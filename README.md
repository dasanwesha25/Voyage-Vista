# 🌍 Voyage Vista

Voyage Vista is a modern travel planning platform designed to help travelers discover destinations, explore attractions, and plan memorable journeys with ease.

Built with **React** and **Vite**, the application focuses on providing a seamless and responsive user experience while showcasing popular destinations, travel recommendations, and interactive features for trip enthusiasts.

## ✨ Features

* 🗺️ Explore popular travel destinations
* 📍 View destination details and travel recommendations
* 📱 Fully responsive design for desktop, tablet, and mobile devices
* ⚡ Fast and optimized performance powered by Vite
* 🎨 Clean and intuitive user interface
* 🔍 Interactive destination search experience

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript
* HTML5
* CSS3
* Google Maps API *(currently disabled)*

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/voyage-vista.git
```

### Navigate to the Project Directory

```bash
cd voyage-vista
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The application will be available at:

```bash
http://localhost:5173/
```
